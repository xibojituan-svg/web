这些信号一出现，必须立刻拦截

基于真实 Badcase 尸检复盘归纳，每一条都曾经导致过真实退费或客诉。

🔴 D 类熔断红线（立即拦截）
  • 💸借呗/花呗≥12期/网贷报名 → T8-D 协议
  • 👨‍👩‍👦家人不知情+家庭负债+0积蓄 → T8-D 协议
  • 💻年龄≥70+不会基础操作+资金困难 → T8-D
  • 🗣️出现"不退款就跳/投诉/找媒体" → T8-D
  • 🕵️零发言+高密度下载+诱导加私微 → T0 卧底
  • ⏱️付款<12小时+花呗≥6期 → C2强制降级
🟡 黄色预警（48h摸底观察）
  • 🔁花呗6-9期报名 → 标记C2，延迟转化48h
  • ❓体验营3次以上问"几天能赚钱" → 严控预期
  • 📱只有手机没有电脑 → 降维A，不配B模块
  • 😭凌晨发长文自我否定 → T6信号，满配C
  • 🤝"等我资金周转了一定回来报名" → 巴纳姆警报
  • 📥3次推送均无回应 → 强制停止该赛道营销
🟢 绿色信号（加速推进）
  • 📚按时交作业+质量稳步提升 → T2确认
  • 🎯主动在群内统筹排班+开会 → T1-A确认
  • 🔬连续追问底层技术原理≥3层 → T3确认
  • 💬每天≥10条社交发言且配合学习 → T7确认
  • 💳全款付清+无借贷信号 → 可直接推进转化
  • 🏆被批评后主动分析原因不需安慰 → 高弹性确认
💡 三大防误判铁律
  • 🚫沉没成本铁律：印象再好，兜里没钱，大额逼单必出退费
  • 🎭巴纳姆铁律："我一定会回来报名"等于什么都没说
  • 💀幸存者偏差铁律：研究活人会让你自我感觉良好，解剖退费才是进步
  • 🤐沉默≠摆烂：话少但每个任务都完成了，是T2不是T8
  • 🎮社交≠低动机：聊家常的人里，可能有主动统筹的T1-A
  • ⏰7天复查机制：所有临时标签7天内必须复核完整判定树
05   配方矩阵

四大服务积木仓库 · 按用户定制拼装

不是所有人都要同样的服务。配错了模块，不仅浪费，还会把人弄烦或者造成退费。

T1专供T1-A统筹混合体3号提干
✅ 核心原则：短板决定总分

资源底座的四个维度（钱/时间/设备/数字能力）中，最短的那条腿决定总分。哪怕她有很多钱，但是完全不会操作电脑，那她的资源底座就是"低"。在此基础上配 B 模块只会把她搞崩溃。
