# 🎯 小白训练营核心课：手把手创建你的第一个 Skill

---

## 一、先说清楚：Skill 到底是什么？

把 Claude 想象成一个刚入职的新员工。

你有两种用法：

- **没有 Skill 的用法**：每次都要从头说一遍"我是做什么的、我要什么风格、这次帮我写一篇朋友圈文案"——每次重复，效率低，输出质量也不稳定。

- **有 Skill 的用法**：你提前写好了一份"岗位说明书"，里面写清楚了：你是谁、输出格式是什么、什么词不能用、什么风格要坚持。以后你只需要说"帮我写今天的朋友圈"，它直接按规矩出活。

**一个 Skill = 岗位说明书 + 工作模板 + 输出标准**

---

## 二、选一个最贴地气的案例：「朋友圈文案助手」

> 适用人群：任何需要经常发朋友圈做个人品牌的人  
> 为什么选这个案例：人人都能用，不需要任何行业背景，效果立竿见影

**没有 Skill 的时候你怎么做？**
每次打开 Claude，要先说一大堆：
> "我是做培训的，朋友圈要亲切不要太商业，语气像朋友聊天，不要用'赋能''闭环'这些词，字数控制在150字以内，要有一个吸引人的开头……"

写了一次还好，写第20次的时候你还记得说这些吗？

**有了 Skill 之后：**
你只需要说一句话：`帮我把今天这件事写成一条朋友圈：我给学员做了1对1辅导，她说终于搞懂了AI怎么帮她省时间`

剩下的，Skill 全搞定。

---

## 三、实操：三步创建你的第一个 Skill

### 第一步：准备你的"标准参考文件"

在自己电脑上新建一个文本文件，取名叫：`朋友圈风格参考.txt`

里面写上你的真实要求，比如：

```
【我是谁】
我叫大卫，在西博教育做AI培训，专门教职场人用AI提升工作效率。
我的学员主要是35岁以上的职场人和中小企业主。

【发朋友圈的目的】
建立个人信任感，让身边朋友和客户觉得我是一个懂AI、真心帮人的老师。
顺带吸引对AI感兴趣的潜在学员。

【语气风格要求】
- 像朋友聊天，不要像广告
- 真实、有温度，可以分享小挫折和真实感受
- 不用"赋能""闭环""链路"这类词
- 偶尔可以有一点自嘲和幽默

【格式要求】
- 字数：100-180字
- 开头第一句必须吸引人，让人想继续看
- 最后可以加一个轻松的问句或行动号召，但不强迫

【过去发过的好文案（参考风格）】
例1："今天给一个学员演示了用AI整理会议记录，她目瞪口呆盯着屏幕看了整整30秒。
以前她整理一份记录要花40分钟，现在3分钟搞定。
这种反应，是我最喜欢的时刻。
你身边有没有这样'被AI震惊'的瞬间？"

例2："不会用AI≠不够努力。
很多人其实很拼，就是没人教正确的方法。
这也是我为什么做这个培训的原因——
不想让大家在错误的路上浪费时间。"
```

---

### 第二步：让 Claude 帮你生成 Skill 文件

打开 Claude（桌面版），直接粘贴这段提示词：

```
我上传了一份关于我的朋友圈写作风格的参考文件。
请根据这份文件，帮我创建一个专业的朋友圈文案 Skill。

这个 Skill 需要包含：
1. 角色设定（这个AI助手是谁、有什么职责）
2. 工作流程（收到需求之后怎么一步步处理）
3. 风格规范（语气、用词、禁止项）
4. 输出格式模板
5. 质量检查清单（输出之前自己核对的标准）

请输出为一个完整的 Skill 文档，格式清晰，我可以直接保存使用。
```

---

### 第三步：测试、挑毛病、反馈修改

Skill 生成之后，马上用真实需求测试：

```
用这个 Skill 帮我写一条朋友圈：
今天开了一堂直播课，有学员说听完之后当天就用AI省了2个小时工作时间。
```

看输出结果，对照你的真实感受：

- 语气对不对？
- 开头是否吸引人？
- 有没有用了你不喜欢的词？
- 字数合适吗？

然后直接告诉 Claude：
> "这个结果第一句开头太平了，帮我把 Skill 里的开头规范改一下，要求开头必须有一个具体的数字或者场景细节，更有画面感"

Claude 会自动更新 Skill 文件。如此反复2-3次，一个真正好用的 Skill 就做好了。

## 四、课堂现场实操安排（建议流程）

| 时间 | 内容 | 目标 |
|------|------|------|
| 0-5分钟 | 讲师展示：没有Skill vs 有Skill的输出对比 | 让学员直观感受差距 |
| 5-15分钟 | 每人写自己的"风格参考文件"（用模板填空） | 完成第一步 |
| 15-25分钟 | 粘贴提示词，让Claude生成自己的Skill | 完成第二步 |
| 25-35分钟 | 用真实需求测试，提出修改意见 | 完成第三步 |
| 35-40分钟 | 2-3名学员展示自己的成果，大家互相点评 | 强化学习 |

## 五、给讲师的关键教学提示

**1. 学员最容易卡住的地方：第一步不知道怎么写"参考文件"**

解决方法：给他们一个填空模板，不用从零写，只需要把括号里换成自己的内容：

```
我叫（姓名），做的是（工作/业务）。
我的主要客户/读者是（什么样的人）。
我发朋友圈/写文案的目的是（什么）。
我喜欢的风格是（形容词），不喜欢（什么风格）。
有几个词绝对不能用：（列举）。
这是我觉得写得最好的一段话，风格可以参考：（粘贴例子）
```

**2. 让学员意识到 Skill 是可以持续进化的**

不要追求第一次就完美，每次用完之后发现有问题，告诉 Claude 修改一下，Skill 会越来越好用。就像雇了一个员工，慢慢培养就越来越顺手。

**3. 可以延伸的应用场景（激发学员想象力）**

- 销售跟进邮件 Skill（统一风格，不用每次想模板）
- 周报总结 Skill（输入要点，自动生成格式化周报）
- 学员反馈回复 Skill（快速、有温度地回复学员留言）
- 招聘描述 Skill（统一公司对外招聘的语言风格）
- 小红书选题 Skill（每次给几个关键词，自动生成5个备选标题）

---

## 六、课后作业（学员带走练习）

> 在这节课结束后的24小时内，完成以下三件事：
>
> 1. **找到你工作中最重复、最烦人的一件写作/整理任务**
> 2. **写一份"参考文件"，描述你的标准和风格**
> 3. **让 Claude 帮你生成 Skill，测试一次，把结果发到群里**
>
> 发到群里的同学，讲师会一对一给反馈建议。
